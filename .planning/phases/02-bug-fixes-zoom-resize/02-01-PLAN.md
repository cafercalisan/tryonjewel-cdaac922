**PremiumHero.tsx zoom safety:**
- In the `animate` function (lines 118-138), the canvas clear uses `canvas.width`/`canvas.height` (which are DPR-scaled) but fills the gradient to those same values. Since ctx.scale(dpr) is applied, the fillRect should use logical dimensions (`window.innerWidth`, `window.innerHeight`), not physical pixels. Audit and fix: store logical width/height in a ref (e.g., `sizeRef`) updated during resize, and use those values in the animate loop instead of reading `window.innerWidth`/`window.innerHeight` live (which is a layout thrash on every frame).
- Specifically: create a `sizeRef = useRef({ w: 0, h: 0 })` that gets updated in the debounced resize handler. Replace all `window.innerWidth`/`window.innerHeight` reads inside the `animate` function (lines 131-132) with `sizeRef.current.w`/`sizeRef.current.h`.
- This eliminates layout thrashing on every animation frame and ensures zoom changes are picked up only on debounced resize.
